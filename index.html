Tentang Saya

Dedikasi Pada Pengalaman & Antarmuka Pengguna

Perjalanan, fokus minat, dan pendekatan saya dalam pengembangan antarmuka web.

Saya merupakan lulusan D3 Teknik Informatika yang berfokus pada pengembangan sisi depan aplikasi web (Frontend Development). Bagi saya, antarmuka yang baik bukan hanya tentang estetika visual semata, melainkan bagaimana pengguna dapat memahami alur informasi dan menyelesaikan tujuannya dengan mudah, cepat, dan tanpa hambatan.

Keseharian saya berpusat pada teknologi web inti seperti HTML, CSS, dan JavaScript, didukung ekosistem styling modern seperti Tailwind CSS, Shadcn/ui, dan Bootstrap. Selain itu, bekal pemahaman dasar bahasa backend (PHP, Python, Java) serta basis data (MySQL, PostgreSQL) memungkinkan saya memahami bagaimana struktur data dialirkan dari server ke antarmuka, sehingga proses komunikasi dan integrasi dengan pengembang backend dapat berjalan selaras.

Responsive & Mobile First
